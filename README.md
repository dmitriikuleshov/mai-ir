# Лабораторная работа №1. Анализ корпуса документов

В работе я исследую три источника англоязычных технических текстов:

Wikipedia, arXiv HTML, Microsoft Learn


## Файлы

- `notebooks/wikipedia.ipynb` — Wikipedia;
- `notebooks/arxiv.ipynb` — научные статьи arXiv в HTML;
- `notebooks/microsoft_learn.ipynb` — техническая документация Microsoft Learn.

Каждый ноутбук самостоятельно:

1. скачивает примеры документов или читает ранее сохранённую выборку;
2. сохраняет их в обычный JSON-файл в каталоге `data`;
3. выделяет текст и метаданные;
4. считает количество документов, размеры сырых данных и текста, средние размеры;
5. рассматривает существующий поиск и его недостатки.

## Запуск

```bash
uv venv
uv pip install -r requirements.txt
uv run jupyter notebook notebooks
```

## Связь со второй лабораторной

В первой лабораторной MongoDB не используется. JSON-файлы содержат только небольшие
примеры для анализа. Во второй лабораторной поисковый робот будет сохранять полный корпус
в MongoDB. Для каждого документа планируются поля `source`, `source_id`, `url`, `title`,
`raw_html`, `text`, `metadata`, `raw_size`, `text_size` и `fetched_at`.
